A [make.fun](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) entry for "Office Artifacts: The One-Line Placard Contest": a museum placard for an ordinary office object, treated as an ancient artifact dug from a lost civilisation.

> Microwave, c. 2004. Enamelled steel. Ritual vessel for reheating offerings; its bell marked the end of the working day. Donated by Accounts.

The placard is 140 characters, inside the 180-character gate, and it was picked from six candidates for the most specific invented history: a microwave is not just old, it is a ritual vessel — and its bell, the sound every office worker knows, is what marked the end of the working day.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
